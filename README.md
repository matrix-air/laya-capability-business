## 主要结论（全部有实测出处）

- **边界在一层算术以内**：英文路径下比较 0.85–1.00，一旦要求求值或多步计算掉到 0.45–0.50。
- **成绩对「检查点 × 语言」极敏感**：0.008 到 0.672，八十倍。任何结论必须同时写明
  检查点 + 语言 + 输入形状。
- **机器人奖励场景不进决策环**：状态盲率 1.000，376 组命中 0.638 输给逐命题查表 0.769。
- **微调两轮全阴性**：模板留出 0.39→0.94，真实留出一动不动，阻断级捕获 0.40→0.00。
- **引擎已换 laya-mlx**：600/600 标签一致，冷加载 10.6×、延迟 2.7×。
- **转人工闸门失效**：act 头在三检查点上最大 P(escalate) = 1e-4。
