## 页面讲什么

把开源决策模型 **Laya**（`convaiinnovations/laya` 0.3.4，Apache-2.0，2.2 GB 权重）
的能力边界拆成两张清单：已经能做的（五条）和做不到的（四条），每条都挂本机重跑的实测数字。

**能做的**：封闭选项分类（零样本 94.4%）、置信度校准（垃圾输入塌到 0.013）、
同信息量下强于关键词规则（0.951 vs 0.803）、一次前向并行答多问（n=10 时 13.5 ms/问）、
完全本地可商用。

**做不到的**：中文意图路由打不过现成方案（55.0% vs 97.67%）、乱码检测低于多数类基线、
专业域微调两轮阴性、`action` 头恒为常量 1.000。

由此推出三个商业卖点（私有化决策层 / 转人工闸门 / 一次问一整套）与两条落地路径。

第 04 节是独立的一组实验：把 Laya 当双足机器人的奖励场景决策器，用 MuJoCo 真值当裁判。
结论是**不进决策环、进人机接口层** —— 它在 376 个决策组上退化成常量（373/376 恒选 walking），
状态盲率 1.000，置信度不再携带信息，给弃权出口也不用。

## 口径纪律

- 凡引用他人自述处（如某竞品宣称的 193.6×/444.6×）一律标注为**官方自评**，不当作第三方数字。
- 成本换算为按公开标价与实测吞吐的**【估】**，非报价。
- 结论的适用范围写明：有真值可测的 5 个场地、小黄鸭（轮足）仿真已有的 8 个命题 / 376 个决策组；
  双足本体尚未接入，属同形状题外推。
- 对照实验一律**信息量对齐** —— 不与「什么都不做」比。
